表头引用跳转
============

表格中有真实外键的列名使用蓝色链接，例如物料版本表的 ``MID``。
点击列名进入被引用的权威表；没有独立菜单的明细表及历史表也可通过引用查看。
目标由当前数据源的外键元数据确定，不按字段名称猜测。
无记录的表格仍显示可用的外键表头链接。

点击具体 ID 或普通数据单元格继续使用原有详情交互；主键表头不因此变成跳转入口。

第一次点击引用表头后，顶部显示“原来的路径 → 当前目标路径”。
左侧整个原路径可以点击返回；继续从其他表头跳转时只更新右侧路径。
返回时恢复最初表格、日期、搜索、筛选和页码。
目标表使用独立搜索，避免来源表的编号搜索把目标表过滤为空。
浏览器刷新、前进、后退保留当前历史项中的引用导航。
主动切换菜单、表格或数据源时结束当前引用导航。

导航使用现有只读查询接口，不修改数据库结构或业务记录。
验证脚本为 ``tests/test_reference_headers.cjs``，支持
``EASYERP_URL``、``EASYERP_PLAYWRIGHT_MODULE``、
``EASYERP_REFERENCE_STAGE`` 和 ``EASYERP_REFERENCE_OUTPUT``。
脚本禁止业务写入，检查当前外键全集、六部门、无独立菜单的目标、
连续跳转、详情保留、历史返回、来源切换、语言、深色及窄屏。
