
当前公司主体与基本信息
======================================================================


贯穿页面左右的顶栏左侧显示公司全称，名称完整显示并可按宽度自动换行；公司名称与「工作空间 / 当前页面」之间以竖线分隔。已移除原蓝色 e 图标和「当前主体」标题；尚未选择时显示「设置公司主体」。点击打开悬浮窗，选择已有公司，查看中英文名、统一社会信用代码、地址（优先办公地址，否则注册地址）和联系电话。点击「详细信息」打开可编辑窗口；「新增主体」创建同一 SQL 主录中的新公司，不虚构名称、证照或联系方式。

选择按正式／演示来源分别保存在浏览器偏好 ``easyerp.company.live/demo`` 中，刷新后保留。来源只有一家公司且尚未选择时自动显示该公司；多家公司时由使用人选择。选择用于界面当前主体和新建手工业务表单中「主体ID／所有权主体ID／开票主体ID」的默认值，仍可在表单内明确选择其他主体；不改写既有记录，也不统一过滤跨部门列表。公司名称及联系资料本身保存在当前 PostgreSQL 数据库，不存入浏览器偏好。

公司唯一主录始终为 ``legal."公司主体档案表"``，原「公司名称」在窗口显示为「公司中文名」。已有编号不变，原字段和外键继续沿用；手工录入、表格编辑、公司窗口共用同一档案。保存复用 ``/api/entry/save`` 的 ``easyerp_app`` 写权限、同源令牌、请求幂等、记录版本冲突与同事务审计。未填写的扩展字段为 NULL，更新只提交实际改动的字段。查看使用只读角色。


字段扩展
----------------------------------------------------------------------


原有字段：主体ID、公司名称、统一社会信用代码、注册地址、登记资料路径、税务资料路径、资料版本、有效状态。

``company_schema.sql`` 独立新增以下可空字段，全部位于既有公司主录中：


.. list-table::
   :header-rows: 1
   :widths: auto

   * - 字段
     - SQL 类型
     - 用途
   * - 公司英文名
     - text
     - 对外使用的英文名
   * - 公司简称
     - text
     - 公司简称资料；顶栏仍显示完整公司名称
   * - 联系电话
     - text
     - 保留区号、分机和原文
   * - 联系邮箱
     - text
     - 对外联系邮箱
   * - 办公地址
     - text
     - 与注册地址分开记录
   * - 官方网站
     - text
     - 公司网站地址
   * - 联系人
     - text
     - 公司对外联系人
   * - 法定代表人
     - text
     - 已掌握的登记资料
   * - 成立日期
     - date
     - 已掌握的登记日期
   * - 经营范围
     - text
     - 登记或业务资料原文
   * - 备注
     - text
     - 其他基本信息


这是在基础规范之外明确实施的可空字段扩展，不改写 ``doc/sql-specification.rst`` 原件或生成的 ``db/001``–``004``。六业务架构、146 张表、主键与外键数量不变。新增字段会自动出现在主录编辑元数据和标准 CSV 模板中；原始业务资料保持不变。


升级与验证
----------------------------------------------------------------------


新环境先按项目原流程安装数据库、手工录入支持，再运行：


.. code-block:: powershell

   $erpConfig = Get-Content .\config.json -Raw | ConvertFrom-Json
   & $erpConfig.python .\tools\enable-company-profile.py


脚本核对 PostgreSQL 数据目录属于本项目，对已有正式库及演示库分别备份，再以事务添加字段及迁移登记；检查原公司资料未改变。重复运行仅核对已安装版本与字段类型，不重复迁移。迁移登记保存在 ``erp_ops.frontend_company_profile_migration``，回执为 ``reports/company-profile-migration.json``。前端 Python 静态资源白名单变更后需重启本项目前端。

``tests/test_company_profile.py`` 与配套浏览器脚本测试新增、切换、编辑、资料一致性、冲突、语言、主题、窄屏及新建业务默认主体；合成数据仅写演示库并清理，核对正式业务数据签名。浏览器依赖和启动方式沿用 ``test_table_edit.py``。数据库标准隔离检查另用 ``tools/easyerp-db.ps1 test``，不把标准样例写入正式库。
