app/ — 应用代码
======================================================================

职责与当前情况
----------------------------

原 frontend/ 改名为 app/：这里同时包含 HTTP 服务、业务查询、录入和浏览器页面，名称与职责一致。Markdown 功能说明移到 doc/app/，五个扩展 SQL 移到 db/app/。

修改与维护方式
----------------------------

修改服务在 ``app/*.py``，界面在 app/web/，先沿用现有模块间调用。配置读取仍以项目根目录为准。服务路径已改为 app/server.py；var/frontend.json 和日志名保持兼容。
