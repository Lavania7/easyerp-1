计划公式展示与主录分类菜单
================================

2026-11-15：对应 ``feedback-1.0.md`` 第 2、4 项。

生产计划
--------

计划的新建与查看窗口居中展示。生产部门计划在表单右侧展示净生产量、物料需求及预计工期三组 LaTeX 公式；窄屏时放在表单下方，内容可滚动，关闭和保存按钮保持可见。工作流、审计继续使用原有浮窗布局。

当前为公式视觉预览，尚不读取实际需求、库存、BOM 和产能，也不自动计算或写回生产数量。变量需要按同一产品、单位、期间和产能口径确认。既有计划字段、关联记录、保存和处理历史沿用原流程。所有浮层与遮罩禁用背景模糊，资源占用优先；层级通过半透明遮罩和边框区分。

公式使用本地 KaTeX 0.16.22，首次打开生产计划时加载脚本；字体、样式及脚本均由本机服务提供。第三方源码和许可证见 ``app/web/vendor/katex/source.json`` 与 ``LICENSE.txt``。

主录选择
--------

数据库、归档及审计核定记录等主视图使用统一两级菜单。一级为业务分类，右侧三角指向二级；悬停或点击分类，在右侧选择具体表。交付记录和交付明细归入“交付”；产品主数据和产品版本归入“产品”。分类只组织导航，不合并或改写业务表。

菜单保留当前部门、页面、正式／演示来源、查询条件及主录选择记忆。分类来自 ``object-menu.js`` 的顺序规则，未匹配的表以自身名称形成分类，现有可选表均保留一次。

键盘可用上下方向键切换，右键进入二级，左键返回一级，回车确认，Esc 关闭。触屏可点选两级；一级和二级列表分别滚动，内容过多时可滚动到末项。菜单高度按当前视口计算，短窗口也不裁掉内容。打开时自动显示当前分类与表。点击菜单外部、滚动页面或改变视口会关闭菜单；菜单内部滚动保持打开。

验证
----

``tests/test_plan_object_menu.cjs`` 为只读浏览器检查，覆盖六部门主录完整性、菜单交互、选择恢复、计划公式、居中布局、中英德文、窄屏与资源加载；统计业务 POST 请求数，预期为 0。使用项目现有 Playwright 环境，通过 ``EASYERP_PLAYWRIGHT_MODULE`` 指定模块。截图路径可通过 ``EASYERP_SCREENSHOT_DIR`` 设置。
