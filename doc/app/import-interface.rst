
表格导入
======================================================================


工作台右上角「↑ 导入」支持标准主录表CSV的检查、预览和正式导入，以及既有6类外部表格的格式检查。标准主录表固定启用，管理页面没有停用按钮；其他类型可停用或恢复。


标准CSV
----------------------------------------------------------------------


1. 点击「标准主录表下载」，下载对应部门的空模板。
2. 保留文件名、原始中文字段名和列顺序，从第2行填写，每行一条记录。
3. 在导入窗口选择文件，核对目标表、记录数、前3条预览和校验提示。
4. 点击「导入正式库」或「导入演示库」。有空缺时确认是否继续；遇到相同编号时选择最新非空值覆盖，或只补原空白项。取消不写业务数据，失败整批回滚。
5. 在「检查记录」查看检查及导入结果；同一次检查重复提交不重复写入；重新检查允许再次导入同一文件。

标准CSV覆盖当前SQL的146张基础主录表。每批最多5000条、单文件最多16MB；支持UTF-8及GB18030，推荐模板原有的UTF-8 BOM、逗号分隔和CRLF换行。编号可留空自动生成；空缺经确认保持NULL，真实0保留为0。精度、日期、状态、已填写关联和数据库业务检查继续生效。已有数据按所选方式合并，新CSV空白永不清除旧值。用户授权的空缺约束调整仅在新增缺失记录时按字段执行并审计，详见`空缺处理说明 <preferences-and-standard-import.rst>`__。

检查阶段试写后回滚，不保存业务记录或约束调整。执行时重新核对文件校验值、检查记录所属来源和SQL字段签名。PostgreSQL的既有前端审计保存批次、文件SHA256、目标主录、源行号、合并选择及修改前后值；同一事务中写入业务与审计。本机SQLite保存检查元数据、标准CSV前3条预览和执行结果，上传原文件不保存。已完成批次可在检查历史查看；重新检查同一文件会开启新的导入操作。


既有外部格式
----------------------------------------------------------------------


.. list-table::
   :header-rows: 1
   :widths: auto

   * - 表格类型
     - 已登记格式
   * - 平台销售订单
     - XLSX，export工作表，32列或29列
   * - 企业网银流水
     - XLSX，Sheet0，第2行表头及HISTORYDETAIL标记
   * - 企业聚合结算流水
     - XLSX，sheet1，14列
   * - 支付宝账务明细
     - CSV，第5行表头，12列
   * - 支付宝账务汇总
     - CSV，第5行表头，6列
   * - 保证金流水
     - CSV，第1行表头，12列


这些格式仍只检查结构，不执行业务映射或写入。启停设置对整个工作空间生效，检查历史按正式/演示分开，重启后保留。未知结构不自动登记。XLS、XLSM、宏、外部链接及说明文字不自动作为业务数据处理。文件上限16MB；XLSX最多20张工作表、每张100000行和256列，总计2000000单元格，解压上限96MB。


接口
----------------------------------------------------------------------


所有POST必须带当前页面的``X-EasyERP-Token``，并通过本机Host/Origin校验。


.. list-table::
   :header-rows: 1
   :widths: auto

   * - 方法与路径
     - 用途
   * - GET /api/import/meta?mode=live或demo
     - 类型目录、SQL模板格式、大小限制及页面令牌
   * - POST /api/import/check?mode=...&filename=...
     - 原始文件字节检查，Content-Type为application/octet-stream
   * - POST /api/import/execute?mode=...&filename=...&check_id=...
     - 再次提交同一文件字节，按确认方式整批导入标准主录表
   * - POST /api/import/settings?mode=...
     - JSON：type_id、enabled、version；标准主录表不可停用
   * - GET /api/import/history?mode=...&offset=0
     - 分页检查及执行结果
   * - GET /api/import/events
     - 最近50次类型启停变更


执行参数另有 ``allow_incomplete=true/false`` 与 ``merge=latest/fill_empty``：有空缺必须显式确认true；有匹配编号必须选择合并方式。文件、来源、检查编号和参数在同一次重试中必须一致。

``format_eligible`` 仅表示格式许可；``can_execute`` 还要求标准CSV业务校验通过、具有记录且尚未完成导入。其他类型始终不可执行。检查结果不等于已入库，入库以PostgreSQL批次审计为准。

验收：``tests/test_standard_import.py`` 在独立演示库验证标准导入并清理测试数据；``tests/test_standard_templates.py`` 逐表验证下载；``tests/test_import_interface.py`` 继续验证既有36份样例和类型管理。主题和语言说明见`偏好与标准导入 <preferences-and-standard-import.rst>`__。


本机Agent文件导入使用`同一业务规则 <../global-rules.rst>`__及` 导入箱流程 <../import-workflow.rst>`__，通过 ``tools/import_inbox.py`` 复用本模块服务，不增加第二套入库规则。
