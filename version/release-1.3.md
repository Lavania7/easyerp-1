# 内容类
1. 归档/生产/供应商档案表 应新增供应的物品，也就是引用归档/研发/物料主数据表的ID
2. “审计”按照视图上面已有的“全年”，Q1到Q4以及具体时间来筛选，删除“审计报告”，“年度审计”等按钮与其对应的功能；点击选择某部门的审计情况时，也不要显示“核定记录”，而是和其他普通表视图一样，使用二级菜单的普通视图展示。删除这些按钮对应的分类逻辑和数据字段
3. 单独在左侧的“归档”，或者叫“静态数据”下面，新增一个“部门交付”的按钮，然后把每个部门的“交付”这个一级分类里面的内容单独拿到“部门交付”这个视图里面看，原来的二级菜单就是“部门交付”表里的一级菜单
4. 把“仪表盘”分成两部分，另一部分叫“映射视图”，点击这个视图的时候，横着的“部门”和纵着的“计划，工作流，数据库和归档”等等，要能交汇在面板上的一个方格里。当选中一个方格的时候，高亮它，然后把其他的亮度调暗，然后用箭头指出它和其他地方的数据流向，不选的时候就隐藏箭头，所有方格的亮度正常；然后，把部门选择的栏和最左边的功能栏，都做成能够横向或者在范围内竖向滚动来显示所有内容的样子；滚动时，中间的视图也应该跟着动；用鼠标可以拖拽中间的视图，上左两栏也跟着动。只有这个视图能实现此操作
5. “计算器”，要能够编辑latex公式，然后按编辑好的latex公式把参数放进去算，类似一个小的计算脚本窗口。latex公式要能预览和选择
