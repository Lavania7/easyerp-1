# easyERP 经营工作台

访问地址：[经营工作台](http://127.0.0.1:8092/)。数据库及网页服务均在本机，页面不依赖外部网络、在线字体或前端框架。

本轮范围依据 `D:\projx\demo\easyerp-0.1\temp\dashboard.md` 的第一版五个入口，并采用已上线 SQL 标准视图。
提供查询、筛选、主录追溯、CSV 导出和手工录入。点击右上角「＋ 录入」选择业务；在记录详情中可以修改主录。具体流程见 [手工录入说明](MANUAL_ENTRY.md)。

## 页面与操作

- **经营总览**：分别显示订单商品实付、核定收入与成本、资金收支、待发货及待完成事项；点击指标进入构成记录。
- **我的工作**：列出状态明确的用途待核定、未验收到货、生产待登记、售后、履约和整改事项。当前未建立登录身份，展示全部待办，不代表按个人分派。
- **销售**：按北京时间的订单创建日期、CNY、文字和履约进展查询；订单详情关联商品、逐次发货、工单、结算、发票、售后和需求。
- **生产**：按计划开始日期、文字与负责人查询；工单详情显示固定发布批次、BOM、领退料、工时、完工、报废和发布文件。
- **财务**：按北京时间的资金发生日期、CNY、主体和文字查询；资金详情分开显示整笔资金、用途、结算、来源文件、内部划转、重复记录和已过账分录。
- **采购与库存、研发、法务、分析报告**：提供标准视图和权威主录的选择、搜索、分页与追溯入口。以上模块均可从手工录入入口填写对应业务主录。

详情分为基本信息、关联明细、业务进展、文件与依据四区。编号链接可继续进入对应部门主录；文件路径可复制后在本机打开。
详情显示该对象的完整关联历史；返回列表时保留原筛选。经营总览的搜索跨期间查找订单、工单、资金、采购、项目、产品和客户。

标准视图之外的主录浏览器不统一套用日期、币种筛选，因为各表日期和金额含义不同；日期不适用时隐藏日期控件；主录追溯保留记录原始币种，不换算或重标历史外币金额。
从收入成本卡片进入时，沿用确认月份、币种与已核定范围。
待完成卡片采用截止日和当前状态，不用开始日截断以前发生而尚未完成的事项。

## 数据口径

- `NULL` 显示N/A，不替换为零；部分核定缺失时显示待核定。计数中的 0 表示查询范围内已登记记录的数量，不代表缺失金额或库存为零。
- 工作台金额查询及导出固定采用CNY；新录入币种固定为CNY。历史主录及其关联证据保留原币种；数量保留单位。金额以精确十进制字符串传输与导出，避免 JavaScript 浮点数改变精度。
- 资金收支剔除已核定重复记录，将已核定内部划转单列；尚未核定的匹配不擅自剔除。
- 毛利保留待核定，因为“收入与成本均按一致不含税口径”的业务批准尚未建立，界面不会把简单相减自动认定为毛利。
- 库存首页显示期间收发，不在缺少核定基准和适用换算时推定完整结存。
- 待履约、待完成依据已登记实际事件及**当前**取消/关闭状态，不是任意历史日期的状态快照。组合商品/单位不一致时保留待核。
- 工作台固定北京时间（UTC+8，Asia/Shanghai），已移除时区与币种选择；旧链接中的其他时区、币种会归一为北京时间和CNY。查询日期边界、时间显示、导入历史与手工录入均采用北京时间；不改写原始业务时间事实。
- 核对问题是提示，不代表相关记录已经完成业务审核。

## 正式数据与演示数据

初次打开使用正式库 `easyerp_v02`。左下角点击带蓝点的“本机数据库”，在悬浮菜单选择“演示数据”切换至独立库 `easyerp_v02_ui_demo`，演示来源显示黄点及“演示数据”，并保留页面演示提示。
演示记录仅用于体验，不代表真实经营事实；从数据源菜单选择“本机数据库”可返回正式库。
演示库由 `frontend\setup_demo.py` 一次建立，后续重跑保留已有演示记录，不重建正式库。

## 导出

列表及标准视图提供“导出明细”，使用当前数据源与筛选条件，CSV 为 UTF-8 BOM，兼容 Excel 导入。
最多导出 10,000 条，超过时页面明确提示导出条数及当前总数；请缩小查询范围后分批导出。
NULL 输出 `\N`，空字符串和数字 0 独立保留；可能被电子表格执行的文本公式会加单引号保护。
经营总览和待办页的导出按钮禁用，先进入对应明细再导出。

## 运行与维护

网页服务可直接通过上述地址访问。现已提供项目根目录 `dashboard.exe` 和桌面“easyERP-Dashboard”快捷方式；数据库登录启动配置保持不变。
需要重启前端时，可使用运维入口：

```powershell
Set-Location 'D:\projx\demo\easyerp-1'
.\bin\start-frontend.ps1 -OpenBrowser
```

该入口先启动现有数据库，再检查或隐藏启动前端；仅启动本项目进程。双击入口封装了同一启动流程，日常无需输入命令。
页面端口为 8092，数据库端口仍为 55433。日志为 `var\log\frontend.log` 及 `frontend-error.log`。
前端只绑定 `127.0.0.1`。查询使用 `easyerp_read` 的只读事务，手工保存使用现有 `easyerp_app` 并在同一事务记录审计；密码留在服务端，不发送到浏览器。
这是单机业务工具，尚未实现多人登录、人员权限及公网部署。

## 验证与文件

`tests\test_frontend.py` 对真实数据库和 HTTP 接口执行测试，报告为 `reports\frontend-tests.json`。
覆盖所有 15 个规范视图及 3 个运维视图、端到端追溯、筛选、分页、币种分离、重复及划转排除、时区日期边界、精确数值、CSV 和只读边界。
测试临时记录仅写入演示库，结束后清除；正式库行数在测试前后核对。
浏览器验证覆盖经营总览、订单/工单/资金详情、四区切换、筛选与导出，以及窄屏布局。

`data.py` 保存查询与关联口径；`server.py` 提供本机查询与受保护的保存接口；`entry.py` 负责表单元数据、校验、事务写入与审计；`web\` 保存无需编译的 HTML/CSS/JavaScript。
本轮未修改 readme.md、dashboard.md 或规范 SQL 定义。

手工录入的独立验收报告为 `reports/manual-entry-tests.json`；新环境需先运行 `bin/enable-manual-entry.py` 安装已确认的附加审计支持。

## 表格导入接口

右上角「↑ 导入」支持标准主录表CSV检查、预览及整批导入，覆盖SQL的146张主录表；该类型始终启用。既有6类外部格式继续支持结构检查与启停管理，未知格式不会自动接纳。空缺经确认后保留为NULL；已有记录可用最新非空值覆盖，或只补原空白项，新CSV空白不会清除旧数据。执行失败整批回滚，同一次检查重复提交不重复写入；重新检查可再次导入同一文件。用户授权的空缺约束调整按字段执行并记录，主键、已填写关联、数值检查及已过账保护继续生效。见[导入说明](IMPORT_INTERFACE.md)。

`imports.py` 使用标准库读取 XLSX/CSV/TXT 并管理本地记录；`import_formats.json` 保存明确登记的识别规则；`var/import-interface.sqlite3` 保存启停设置和检查历史，重启后保留。记录按正式/演示来源分开，类型设置工作空间共用。验收为 `tests/test_import_interface.py`，报告为 `reports/import-interface-tests.json`。

顶部主题按钮在浅色、深色、跟随系统间循环；语言按钮在ZH、EN、DE间循环，刷新后保留选择。右上角显示接口声明的Read／Write／R&W权限及北京时间hh:mm:ss实时钟；页面不再显示查询完成时间。日期使用纯文字按钮，浏览器原生日历图标完全不可见；点击文字打开日期选择器。数据源入口打开悬浮菜单，由菜单明确选择正式或演示数据，支持键盘及点击外部关闭。标准主录表下载入口为侧栏底部的“下载”按钮，位于数据源分隔线上方。详见[主题、语言与标准导入](PREFERENCES_AND_STANDARD_IMPORT.md)。

中文优先使用本机已安装的思源黑体简体中文可变字体，英文沿用Fira Code；字体栈包含system-ui及sans-serif系统回退。本机缺少字体时使用随项目离线提供的Adobe官方WOFF2，许可证与来源校验见web/fonts/。N/A仅为未知值的界面显示，数据库NULL与CSV中的\N不变。
